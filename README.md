## 🌸 About Me

I'm a passionate developer specializing in **C#/.NET**, web technologies and automation. I enjoy building practical software, scripting useful workflows and understanding the systems behind an application — from code and databases to deployment, networks and end-user support.

- 🔭 Building web and mobile applications with **C#/.NET, ASP.NET and Capacitor**
- ⚙️ Working with **Docker, Kubernetes, CI/CD and self-hosted infrastructure**
- 🖥️ Interested in **systems, networks, security and IT administration**
- 🤖 Exploring **AI agents, automated workflows and responsible AI use**
- 🎮 Interested in game development, Minecraft mechanics, seed generation and technical modding
